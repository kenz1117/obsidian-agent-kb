# Data Governance

**Languages:** [中文](DATA-GOVERNANCE.md) | English

Raw input is not knowledge.

Every object must have:

- provenance
- source
- confidence
- sensitivity
- lifecycle status
- retention policy

Canonical status requires governance approval.
